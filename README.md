# Aeries — AI Tech Buddy Chatbot

A simple, friendly human-interface chatbot built with pure HTML, CSS, and JavaScript. Aeries chats with you about common programming terms and responds to everyday greetings.

## Features

- Chat with the bot by typing messages or pressing Enter
- Understands common greetings: Hi, Hello, Hey, Good morning, Good afternoon, Good evening
- Answers questions like "How are you?", "What is your name?", "Who are you?", "What can you do?", and "Help"
- Explains programming terms: HTML, CSS, JS/JavaScript, React, Python, Java, Node.js
- Replies to Thanks, Thank you, Bye, and Goodbye
- Friendly fallback response for unrecognized messages
- Voice input button (when supported by the browser)
- Light / dark theme toggle
- Login / Sign Up modal (demo, stored locally)
- Responsive design for desktop and mobile

## Technologies

- HTML
- CSS
- JavaScript

## How to run the project

1. Open `ars.html`
2. (Optional) `landingpage.html` links to the chatbot — open either file directly in a browser
3. No server, build step, or external AI API is required

## Basic chatbot functionality

Type a message in the input box and press **Enter** (or click the send button). The user message appears on the right and the bot's reply appears on the left. Empty messages are ignored, and unknown questions get a friendly fallback response.
